# Coffee, Tea & APTs

> **Brewing detections, spilling threat intel tea, and tracking APTs.**

Coffee, Tea & APTs is a public threat intelligence briefing, Detection-as-Code (DaC) registry, and adversary research portal built for security analysts, defenders, and detection engineers.

**Live Portal:** [https://coffeeteaapts.com](https://coffeeteaapts.com)

---

## What Is Included

* **Curated Threat Stream:** Real-time aggregation from authoritative OSINT feeds (CISA KEV, The Hacker News, BleepingComputer, SANS Internet Storm Center) correlated with CVE and MITRE ATT&CK indicators, featuring automatic read-state tracking and advisory dismissals.
* **1,500+ Multi-Platform Detections:** Production-grade detection rules categorized across the 14 MITRE ATT&CK Enterprise tactics and core platforms (Cloud, Identity, Windows, Linux, Network) across five major query formats:
  * Splunk (SPL)
  * Elastic (EQL & ES|QL)
  * Sigma (YAML)
  * Google Chronicle (YARA-L 2.0)
  * CrowdStrike Falcon (FQL)
* **Muninn Blog:** Technical research papers covering adversary tradecraft, telemetry blind spots, and detection engineering mechanics.
* **Colorblind-First Interface:** Default Okabe-Ito high-contrast colorblind-safe palette, plus 6 selectable tactical dark themes.
* **Privacy & Architecture:** Pre-compiled static architecture with zero runtime tracking, zero cookies, and full client-side search and filtering.
